# Investor AI visual system

Extend the original site using its Cormorant Garamond headings, Inter body, #f7f5f0 background, #fffdf8 paper, #111 text, and fine neutral borders. New financial charts use restrained forest green. Keep existing IR HTML and assets, changing only navigation and an additive product section.

Concept: `.design/investor-ai-concept.png`, generated with the built-in image tool. Native code implements all text, charts, controls, and indicators. Horizontal product tabs, four-column KPI band, two-column chart/insight workspace, scenario/source tables. Mobile collapses panels and uses horizontally scrollable tabs. Exact financial values are calculated from explicit synthetic fixtures, superseding illustrative numbers in the concept. Extend IPO, document, connection and chat views in this same design system.
